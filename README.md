# Sistem Pengelolaan Pengeluaran Harian

## Deskripsi
Program Python untuk mencatat, menyimpan, mengolah,
menganalisis, dan melaporkan pengeluaran harian.

## Fitur
- Mencatat transaksi pengeluaran.
- Membaca data transaksi dari file.
- Menghitung total dan rata-rata pengeluaran.
- Menganalisis kategori pengeluaran.
- Membuat laporan otomatis.
- Melakukan pengujian menggunakan unittest.

## Teknologi
- Python
- File Handling
- Object-Oriented Programming
- Modular Programming
- Unit Testing

## Cara Menjalankan
Jalankan perintah berikut di terminal:

python main.py
